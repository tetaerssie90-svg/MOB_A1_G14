# AI Use Declaration

## Overview

This group used AI assistants (ChatGPT / Claude) as development support
tools during the SWE 3409 assignment. AI was used for:

- Explaining React Native and Expo concepts
- Debugging dependency and environment issues
- Generating boilerplate for reusable components
- Reviewing layout and accessibility decisions
- Drafting documentation

AI was **not** used to:

- Generate a full final submission without review
- Write code that a member cannot explain during live verification
- Fabricate test results or evidence

Every member reviewed, understood, and can explain the code they submitted.
